## 失败归因与 Oracle 校准

本轮 3 个失败均为确定性断言与合理 Agent 输出不一致，不应直接解读为模型能力失败：

- D01 的 Agent 将 `oldCleanName` 委托给 `cleanName`，完成了消除重复逻辑；原断言错误期待 `normalizeName`。
- G01 的 Agent 创建了 `Agent Change Log`，并保留了用户 `notes.md`；原断言存在大小写不一致。
- J01 的 Agent 使用中文标题“已观察事实”和“推荐方案”区分内容；原断言错误期待英文 `Decision`。

三个任务的 manifest 已完成校准，后续运行将使用修正后的 Oracle。本报告保留原始运行数字，未将事后校准后的推断结果计入通过率。

## 结论

本轮验证了 16 任务矩阵、真实 Mimo Agent、真实 Mimo Judge、事件轨迹、环境快照和工程指标的端到端闭环。当前主要风险集中在长上下文和脏工作区任务的成本/延迟，以及 Oracle 对自然语言产物的表达容忍度；后续应优先做校准后的重跑，再扩展到 48 任务单次 smoke。
