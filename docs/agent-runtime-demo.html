04 · Permission engine

能力不是裸奔的：
每次调用先过策略层

切换模式查看典型工具类别的默认决策。硬拒绝规则不会因为模式变高而消失，例如递归危险删除、workspace 外写入和 secret 读取。

Safe YOLO 策略预览常见工作区操作自动通过，高风险与未知行为仍询问或拒绝。 mode: yolo
动作类别示例默认决策策略依据
Workspace 边界

外部写入硬拒绝；外部读取默认询问，Full 模式可允许。

Secret 防护

.env、token、credential、private key 等路径读取硬拒绝。

Command 分类

测试 / lint / build 可放行；安装、网络和未知命令提升风险；破坏性命令硬拒绝。
