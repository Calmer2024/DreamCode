设计规则

所有产品界面与组件实现必须遵循以下基础约束。

Required
图标只能来自 Icon 组件库

不使用任何 Unicode 字符图标或 Emoji 图标。箭头、更多、关闭、窗口控制等也必须通过统一的 Icon 组件渲染。

禁止用文本模拟图标

不可使用符号字体、字符实体或特殊字符拼出图标。图标需共享尺寸、描边、颜色与无障碍标签。

统一使用 Noto Sans SC

中文与界面文字使用 Google Fonts 的 Noto Sans SC，正文 400、强调 500、标题 600 或 700。

只引用语义 Token

颜色、间距、边框、圆角和阴影应通过 Token 复用，交互状态不得创建无意义的近似值。

核心 Token

组件必须引用语义变量；禁止在同类组件中另造近似色和近似圆角。
